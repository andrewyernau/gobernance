# Rust Book - Como usar este vault

## Para que sirve

Este vault no reemplaza al libro. Sirve para convertir lectura lineal en conocimiento navegable.

## Flujo recomendado

1. Entra desde [[Rust Book - Hub]].
2. Abre el capitulo que estes estudiando.
3. Salta a los conceptos enlazados cuando algo te resulte confuso.
4. Ejecuta el ejemplo Rust correspondiente.
5. Vuelve a la nota y escribe una observacion propia.

## Criterio de calidad para una nota

Una nota buena deberia responder, como minimo:

- que es;
- para que sirve;
- por que existe;
- como se usa;
- cuando conviene usarlo;
- que error suele cometer un principiante.

## Regla para el grafo de Obsidian

No dejes notas aisladas. Si una nota no enlaza con nada, en la practica no forma parte de tu sistema.

## Tipos de notas

- `00-mapas/`: entradas y rutas.
- `01-capitulos/`: contexto y progreso por capitulo.
- `02-conceptos/`: ideas atomicas que se pueden reutilizar.
