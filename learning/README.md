# Learning

Zona de aprendizaje práctico en Rust.

## Objetivo

Convertir la lectura del libro oficial en código pequeño, ejecutable y fácil de revisar.

## Regla de organización

- Cada capítulo tiene su propia carpeta.
- Cada crate responde a una idea concreta del libro o a un ejercicio derivado.
- Cada capítulo tiene un `README.md` con fuente oficial, utilidad y mapa de ejemplos.

Punto de entrada: [book/README.md](book/README.md)
