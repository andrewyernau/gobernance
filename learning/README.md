# Learning

Zona de aprendizaje práctico en Rust.

## Objetivo

Convertir la lectura del libro oficial en:

- código pequeño, ejecutable y fácil de revisar;
- notas enlazadas pensadas para Obsidian;
- una base clara que termine alimentando el juego sandbox con Vulkan.

## Regla de organización

- Cada capítulo tiene su propia carpeta.
- Cada crate responde a una idea concreta del libro o a un ejercicio derivado.
- Cada capítulo tiene un `README.md` corto para navegación rápida.
- El conocimiento duradero vive en `book/notes/`, no solo en los `README.md`.
