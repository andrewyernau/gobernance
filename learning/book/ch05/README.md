# Capitulo 5 - Structs para modelar datos

## Fuente oficial

- https://book.rustlang-es.org/ch05-00-structs
- https://book.rustlang-es.org/ch05-01-defining-structs
- https://book.rustlang-es.org/ch05-02-example-structs
- https://book.rustlang-es.org/ch05-03-method-syntax

## Codigo

- `defining_structs/`: 5.1 definicion, instanciacion, update syntax, tuple structs y unit-like structs.
- `example_structs/`: 5.2 ejemplo del area para ver por que un `struct` mejora el modelado.
- `method_syntax/`: 5.3 metodos, `&self` y funciones asociadas.

## Orden recomendado

1. `defining_structs`
2. `example_structs`
3. `method_syntax`

## Utilidad

- Empezar a modelar datos del juego con tipos propios.
- Dejar de pasar tuplas anonimas cuando el dato ya tiene significado.
- Preparar chunks, bloques, jugador y configuraciones del mundo.

## Comandos utiles

```powershell
cargo run -p ch05_defining_structs
cargo run -p ch05_example_structs
cargo run -p ch05_method_syntax
```
