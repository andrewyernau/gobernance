## Código

- `variables_and_types/`: variables, shadowing, tipos, tuplas y arrays.
- `functions/`: funciones, parámetros, expresiones y retorno.
- `flow_controls/`: `if`, `else if`, `loop` y `for`.
- `fibonacci/`: ejercicio práctico para consolidar funciones y bucles.

## Utilidad

- Construir una base mental del lenguaje antes de ownership.
- Distinguir sentencias de expresiones.
- Entender cuándo usar arrays, mutabilidad y flujo explícito.
