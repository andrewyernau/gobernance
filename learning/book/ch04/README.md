## Código

- `ownership/`: movimientos, `clone`, paso de ownership y retornos.
- `references_and_borrowing/`: préstamos inmutables y mutables.
- `slices/`: `&str`, primera palabra y slices de arrays.

## Utilidad

- Entender por qué Rust garantiza memoria segura en compilación.
- Aprender a leer errores de borrow checker con contexto.
- Preparar el terreno para `structs`, enums y APIs más expresivas.
