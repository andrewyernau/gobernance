# Capítulo 1 - Empezando

## Fuente oficial

- https://book.rustlang-es.org/ch01-02-hello-world
- https://book.rustlang-es.org/ch01-03-hello-cargo

## Código

- `hello_world/`: ejemplo mínimo compilado con `rustc`.
- `hello_cargo/`: primer proyecto gestionado con Cargo.

## Utilidad

- Entender la anatomía mínima de un programa Rust.
- Diferenciar compilación manual y gestión de proyecto con Cargo.
- Fijar una convención de proyecto antes de crecer.

## Nota

`hello_world` se mantiene fuera del workspace porque su objetivo es mostrar el flujo directo de `rustc`, no el de Cargo.
