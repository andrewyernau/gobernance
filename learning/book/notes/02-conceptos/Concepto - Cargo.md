# Concepto - Cargo

## Que es

El gestor de proyectos y dependencias de Rust.

## Para que sirve

Sirve para crear crates, resolver dependencias, compilar, ejecutar, testear y publicar.

## Por que importa

En Rust casi todo el flujo real pasa por Cargo. Aprender Rust sin acostumbrarte a Cargo es aprender a medias.

## Como reconocerlo

- `Cargo.toml` describe el paquete o workspace.
- `Cargo.lock` fija versiones reproducibles.
- `src/main.rs` y `src/lib.rs` son convenciones habituales.

## Cuando usarlo

Siempre que ya no estes haciendo un ejemplo minimo de `rustc`.

## Error tipico

Pensar que Cargo es solo un comando para ejecutar. En realidad organiza el proyecto entero.
