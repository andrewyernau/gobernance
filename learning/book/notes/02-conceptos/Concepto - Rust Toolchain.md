# Concepto - Rust Toolchain

## Que es

El conjunto de herramientas base para trabajar con Rust: `rustup`, `rustc`, `cargo`, `clippy`, `rustfmt` y la documentacion local.

## Para que sirve

Te permite instalar versiones del lenguaje, compilar, formatear, revisar y documentarte sin depender de herramientas externas.

## Por que existe

Rust cuida mucho la reproducibilidad. El toolchain hace que instalar y cambiar de version sea predecible.

## Como usarlo

- `rustup update`
- `rustc --version`
- `cargo --version`
- `rustup doc --book`

## Cuando pensar en esto

Cuando una guia te falle por version, por edicion o por herramientas que faltan.
